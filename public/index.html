📐 System Design & Scalability Principles

Architectural building blocks for distributed, highly available software systems.

Distributed Systems

CAP Theorem

States that any distributed data store can only simultaneously provide at most two of the following guarantees: Consistency, Availability, and Partition Tolerance.

Traffic Control

Rate Limiting (Token Bucket)

Controls network traffic by holding tokens in a bucket. Tokens replenish at a constant rate; requests consume tokens, preventing DDoS and resource starvation.

Performance

Cache-Aside Pattern

Application queries the cache first. If a cache miss occurs, data is fetched from the database and asynchronously written to cache for subsequent reads.

High Availability

Round-Robin Load Balancing

Distributes client requests equally among an array of servers in a cyclical sequence, preventing single points of failure.
